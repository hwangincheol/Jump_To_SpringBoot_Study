# Jump_To_SpringBoot_Study
점프 투 스프링부트 교재 웹 개발 학습

게시판 서비스를 만들어가는 과정을 설명한 스프링부트 교재를 통해 복습 및 새로운 방식의 코드 진행을 학습하였음.

## 학습 내용
- JPA로 데이터베이스 사용하기
- 엔티티로 테이블 매핑하기
- 리포지터리로 데이터베이스 관리하기
- 질문 목록 만들기
- 서비스 활용하기
- 상세 페이지 만들기
- 답변 기능 만들기
- 웹 페이지 디자인하기
- 부트스트랩으로 화면 꾸미기
- 질문 등록 기능 추가하기
- 네이게이션 바 추가하기
- 페이징 기능 추가하기
- 게시물에 번호 지정하기
- 답변 개수 표시하기
- 스프링 시큐리티
- 회원 가입 기능 구현하기
- 로그인과 로그아웃 기능 구현하기
- 글쓴이 항목 추가하기
- 수정과 삭제 기능 추가하기
- 추천 기능 추가하기
- 앵커, 마크다운 적용하기
